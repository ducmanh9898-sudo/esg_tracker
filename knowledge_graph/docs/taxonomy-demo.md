# Universal ESG Assessment Taxonomy — Demo sample

Demo dùng 30 disclosure record được chọn từ JSON BSR để kiểm tra taxonomy tối thiểu. Các record có giá trị và vị trí nguồn, nhưng chưa được đối chiếu với câu gốc trong PDF.

| Trường | Giá trị demo |
|---|---|
| Dimension | E, S, G |
| Topic | climate, energy, water, waste, workforce, board |
| Claim type | reported_measurement, target, quantitative_change, planned_capacity, governance_statement |
| Expected evidence class | quantitative_disclosure, target_disclosure hoặc governance_disclosure |
| Assessment status | Supported, Contradicted, NeedsReview, InsufficientEvidence, NotApplicable |

Taxonomy này phục vụ prototype. Nó chưa phải taxonomy đầy đủ cho toàn bộ GRI, IFRS S1/S2 và SASB.
